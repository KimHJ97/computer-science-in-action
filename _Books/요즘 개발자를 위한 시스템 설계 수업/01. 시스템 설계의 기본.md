# 시스템 설계의 기본

## 2. 시스템 설계의 다양한 유형

### 2-1. 상위 수준의 시스템 설계
 - __시스템 아키텍처__: 시스템의 전반적인 구조로, 컴포넌트 및 각 구성 요소 간 통신 방식이나 관계 등을 포함
    - 모놀리식: 모든 시스템 구성 요소를 결합한 하나의 독립적인 애플리케이션
    - 클라이언트-서버: 네트워크를 통해 통신하는 작고 독립적인 여러 서비스로 구성된 모듈형 아키텍처
    - 마이크로 서비스: 네트워크를 통해 통신하는 작고 독립적인 여러 서비스로 구성된 모듈형 아키텍처
    - 이벤트 주도: 비동기 이벤트 또는 메시지로 각 구성 요소가 상호 작용하는 시스템
    - 고려 사항
        - 확장성: 서비스 사용자 수가 많아지고, 데이터가 방대해지며, 더 많은 기능이 추가되었을 때도 이를 지원할 수 있는지
        - 유지 보수성: 버그 수정, 디버깅, 성능 개선 작업이 얼마나 수월할지
        - 신뢰성: 시스템이 중단 없이 안정적으로 동작할 수 있는지, 문제가 발생하더라도 기능을 지속적으로 유지할 수 있는지
        - 지연 시간: 아키텍처가 시스템의 응답 시간과 성능에 미치는 영향은 어떤지
 - __데이터 흐름__: 데이터가 시스템을 통해 수집되어 저장 및 처리하는 과정
    - 데이터 수집: 데이터가 어디에서 오는지, 이를 시스템으로 어떻게 가져올지. API를 통해 불러올지, 실시간 스트리밍이나 일정 시간마다 모아서 가져오는 배치 처리할지 고려
    - 데이터 저장: 데이터를 어떻게 저장할지. 데이터에 얼마나 자주 접근하는지, 검색 성능이 중요한지, 데이터가 항상 일관성 있게 유지되어야 하는지 고려
    - 데이터 처리: 데이터를 변환하거나 분석, 요약하는 과정. 지연, 병목 현상 고려.
    - 데이터 검색: 사용자가 처리된 데이터에 어떻게 접근할지. 응답 시간이 얼마나 빠른지, 캐시를 사용하여 속도를 높일지, 여러 요청이 들어올 떄 부하를 어떻게 나눌지 고려
 - __확장성__: 작업량이 증가해도 성능 저하 없이 부하를 처리할 수 있는 능력
    - 수직 확장성: CPU, 메모리, 저장소 등 단이 컴포넌트에 자원을 추가하여 성능을 향상시키는 방법
    - 수평 확장성: 작업 부하를 여러 컴포넌트나 인스턴스로 분산하여 성능을 높이는 방법
 - __장애 허용 시스템__: 오류가 발생해도 시스템이 제 기능을 수행할 수 있는 능력
    - 복제, 중복성, 점진적 성능 저하, 모니터링, 자가 복구

### 2-2. 하위 수준의 상세 설계

 - __알고리즘__: 계산이나 데이터 처리, 문제 해결 과정
    - 시간 복잡도: 입력 데이터의 크기와 연산 횟수의 상관관계를 의미
    - 공간 복잡도: 입력 데이터 크기와 사용하는 메모리양 간의 관계를 의미
    - 트레이드오프: 시스템의 요구 사항과 제약에 따라 시간 복잡도와 공간 복잡도 간 균형을 맞추는 것
 - __데이터 구조__: 메모리 내에서 데이터를 관리하고 운용하는 방식
    - 데이터 접근 방식: 데이터 접근 빈도와 형태로 읽기와 쓰기
    - 쿼리 성능: 검색, 삽입, 삭제 등 작업에 대한 시간 복잡도
    - 메모리 사용량: 데이터 구조와 그 내용물을 저장하는 데 필요한 메모리양
 - __API__: 서로 다른 구성 요소나 서비스 간 통신을 가능하게 하는 인터페이스
    - 일관성
    - 유연성: 기존 기능에 영향을 주지 않으면서 향후에 생길 변경이나 기능 확장 대비
    - 보안: 인증, 권한 부여, 입력 유효성 검사 등을 구현하여 시스템이 허용하지 않은 무단 접근과 데이터 유출에 노출되지 않도록 함
    - 성능: API의 지연 시간을 최소화하고 자원을 효율적으로 사용할 수 있도록 최적화
 - __코드 최적화__: 코드의 성능, 가독성, 유지 보수성을 향상시키는 기법
   - 리팩터링: 기존 기능을 그대로 유지하면서 코드 구조를 재구성하여 가독성과 유지 보수성을 끌어올리는 기법
   - 루프 언롤링: 반복문을 개별 구문 여러 개로 대체하여 반복문을 실행할 때 발생하는 오버헤드를 줄이고 성능을 향상시키는 기법
   - 메모이제이션: 이전 실행 결과를 저장해서 동일한 결과를 다시 계산하는 시간 절약법
   - 병렬 처리: 작업을 더 작고 개별적인 하위 작업으로 나누어 동시에 실행함으로써 전체 처리 시간을 줄이는 기법
